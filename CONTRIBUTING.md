# Contributing

Useful next work: reproduce a clean build, diagnose shutdown/remoteproc stalls, validate WAN/NAT and port mapping, and document a recoverable installation path for additional RN07 units. Keep changes scoped to RN07 and preserve existing upstream copyright notices.

Include the exact board revision, original firmware, source commit, module ABI, controlled reproduction, observed result and recovery outcome. Remove passwords, keys, serials, MACs, public IPs, subscriber information, ART and proprietary firmware before attaching evidence. Do not upload a full device dump.

Claims must distinguish offline validation, a single controlled observation and stable everyday use. Do not report an issue as fixed merely because the next boot worked. No pull request is automatically permission to flash another person's device.
